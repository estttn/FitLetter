## Общие решения (все три)

| Было в исходнике | Сделали | Зачем |
|------------------|---------|-------|
| «Руководитель проектов» + Product + Head of Dev | Разные заголовки под каждую роль | HH не путает с другими профессиями |
| 250к одной строкой | Разные вилки: PM 80–120к (middle), копирайт 60к+, BA 80–100к+ | Под реальный рынок HH, не агрегаторы |
| «hands-on», «конвертировал экспертизу» | Убрали | Звучит как ChatGPT / HR-шаблон |
| «Сильные стороны: …» списком в «Обо мне» | Факты и цифры в опыте | Рекрутер читает достижения, не самооценку |
| Специализации на 3 должности | Одна цель на резюме | Фокус |

**Что сознательно не приукрашали:** нет выдуманных должностей «копирайтер 3 года», нет CBAP, нет «150+ статей». Копирайт и BA — из реальных задач в SSL.

## 1. IT Project Manager

**Файл:** `01-it-project-manager.md`

### Какие боли работодателя закрываем

| Боль HR / PMO | Где в резюме |
|---------------|--------------|
| «Нужен PM с заказной разработкой, не корпоративный IT» | SSL, B2B, проекты под ключ |
| «Боимся срыва сроков» | −35% просрочек, предсказуемость сроков |
| «Нужен человек на конфликтного клиента» | 2 эскалации, клиенты удержаны |
| «Должен понимать ERP / автоматизацию» | 5 named-проектов |
| «Jira / Agile» | Jira, Weeek, Scrum, Kanban |
| «Overqualified Head, но нам нужен PM на проект» | Подача как middle PM, вилка 80–120к — попадание в рынок |

### Что сильное

- Цифры: 8 проектов, 11 ролей, 35%, 2 конфликта — из оригинала, не выдуманы.
- Карьера в одной компании — выглядит как рост, не job hopping.
- UX-период сжат и обоснован одной строкой «зачем PM-у дизайн».

### Чего не хватает (допилить вам)

1. **Размер команд** — «до N человек в команде проекта» (если можете назвать).
2. **Бюджеты проектов** — хотя бы порядок (до 3 млн / 10 млн) — сильно поднимает senior.
3. **1–2 имени стека** — Python, 1С, Bitrix, React — что реально было (для ATS и HR).
4. **Сертификаты** — если нет, не врать; можно позже PSM I.

### ИИ-текст: проверка

| Фраза | Статус |
|-------|--------|
| «без фанатизма» (про методологии) | Ок — живая речь |
| «не с чужих брифов» | Только в копирайте, не здесь |
| «Вытащил конфликтные проекты» | Ок — разговорно, но по делу |
| Длинные цепочки прилагательных | Нет |

### Риски при откликах

- **Overqualified:** на middle 100–120к могут бояться ухода. В сопроводительном: «ищу part-time, 1 проект, 20–24 ч/нед».
- **Текущая работа SSL:** если параллельный PM — проверить договор и конкуренцию.

## 2. Копирайтер B2B IT

**Файл:** `02-kopirajter-b2b-it.md`

### Какие боли закрываем

| Боль заказчика | Где в резюме |
|----------------|--------------|
| «Копирайтер не понимает IT» | 4 года SSL + 9 лет digital |
| «Нужны кейсы, не посты про котиков» | Блок «что могу» + темы проектов |
| «Технарь написал — нужно перевести» | «Переводил язык разработчиков на язык бизнеса» |
| «Part-time / ГПХ» | Явно в цели |

### Что сильное

- Честная подача: не «копирайтер 5 лет», а «тексты из пресейла, КП, ТЗ, UX».
- Список форматов — рекрутер сразу понимает, что заказать.
- Темы из реальных проектов — не абстрактный «FinTech».

### Чего не хватает (критично для копирайта)

1. **Портфолио** — 2–3 PDF: обезличенный кейс ERP, фрагмент лендинга, текст КП. Без этого 60к ок, 80к+ сложнее.
2. **Ссылки на публикации** — если есть (Telegram компании, сайт SSL с вашим текстом) — добавить.
3. **Объём:** «N кейсов / N статей в месяц» — когда сделаете первые заказы.

### ИИ-текст: проверка

| Фраза | Статус |
|-------|--------|
| «без канцелярита» | Ок |
| «не с чужих брифов, а изнутри» | Ок — отличие от типичного копирайтера |
| «Пишу просто» | Норм, не шаблон |

### Риски

- HR может искать «опыт копирайтом 2+ года» — откликаться на «IT-редактор», «контент B2B», «тексты для IT-компании».
- «Портфолио по запросу» — до первого собеса подготовить 1 sample.

## 3. Бизнес-аналитик IT

**Файл:** `03-biznes-analitik-it.md`

### Какие боли закрываем

| Боль | Где в резюме |
|------|--------------|
| «BA не понимает производство / ERP» | Таблица проектов |
| «Срыв на этапе ТЗ» | Чеклист входного ТЗ, шаблоны |
| «Нужен discovery на 1–2 месяца» | «Проектная работа 2–6 недель» |
| «Должен общаться с заказчиком» | Интервью, согласование scope |
| «Прототипы для согласования» | UX-фон, Figma |

### Что сильное

- PM-опыт переупакован в BA-язык: требования, ТЗ, as-is/to-be — без вранья.
- Таблица проектов — быстро сканируется.
- BPMN «базово» — честно, не притворяемся экспертом.

### Чего не хватает

1. **Пример артеfactа** — оглавление ТЗ или 2–3 user story (обезличено).
2. **SQL / API** — не указаны; если в вакансии «системный аналитик» с API — это другая роль, не откликаться.
3. **Отдельная должность в SSL** — сейчас «BA / PM (функции discovery)» — на собеседовании готовить ответ: «70% времени было на требования и ТЗ».

### ИИ-текст: проверка

| Фраза | Статус |
|-------|--------|
| «без „а мы думали иначе“» | Ок — живая формулировка |
| as-is / to-be | Норм для BA, не клише |
| Таблица проектов | Факт, не вода |

### Риски

- «Почему не PM?» — ответ: «Хочу фокус на discovery и документ, part-time или проект».
- Системный аналитик (API, интеграции на уровне схем) — только если готовы углубляться.

## Сводка: три резюме — три разных человека для HR

| | PM | Копирайтер | BA |
|--|-----|------------|-----|
| **Продаём** | Сдаю проекты в срок | Пишу про IT для бизнеса | Собираю требования, пишу ТЗ |
| **ЗП от** | 80–120к (middle) | 60к+ | 80–100к (middle) |
| **Главный proof** | −35%, 8 проектов | Пресейл-тексты, темы | Таблица ТЗ, чеклист |
| **Главный gap** | Бюджеты, стек | Портфолио PDF | Пример ТЗ |
| **Приоритет доработки** | Средний | Высокий (portfolio) | Средний |
